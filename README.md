# TraffiX-AI: City-Wide AI Engine for Multi-Camera ANPR Trajectory Tracking and Urban Traffic Analytics
## Smart India Hackathon 2026 — Problem Statement SIH26127

TraffiX-AI is an edge-to-cloud spatiotemporal AI engine designed for Indian Smart Cities. It combines high-accuracy edge ANPR, road-network kinematic trajectory reconstruction, Indo-HCM compliant urban traffic analytics, and DPDP Act 2023 privacy-by-design.
